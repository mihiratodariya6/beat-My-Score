# 🎯 Beat My Score

A mobile-first, highly addictive browser game where speed and precision matter.

## Features (Step 1)
* **Mobile-First Design**: Optimized touch targets and responsive container.
* **Core Mechanics**: 30-second timer, randomized target positioning.
* **Scoring System**: Tracks live score and consecutive combos.
* **SPA Structure**: Seamless transitions between Start, Game, and Result screens without page reloads.

## How to Run Locally
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. No build tools or servers are required for this phase.

## How to Deploy with GitHub Pages
1. Push these files to a GitHub repository.
2. Go to Repository Settings > Pages.
3. Select the `main` branch and `/root` folder.
4. Click Save. Your game will be live in a few minutes.
